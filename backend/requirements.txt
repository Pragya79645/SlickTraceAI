# CPU-only PyTorch wheels — pinned explicitly. Without this, pip's default Linux
# resolution for `torch` pulls the CUDA-enabled build (~530 MB, vs ~190 MB for the
# +cpu build of the same version) even on a GPU-less host such as Render's free
# tier. That gap, on top of ultralytics/opencv/rasterio all resident at once, is
# enough to OOM a 512 MB instance mid-inference. Verified both these exact pins
# resolve cleanly on manylinux_2_28_x86_64/cp313 (Render) and win_amd64/cp313
# (local dev) via `pip install --dry-run --platform ... --only-binary=:all:`.
